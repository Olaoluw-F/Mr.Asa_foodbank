# Instructions for AI agents

Read `Context.md` before you change anything. It is this project's plan, decisions log, and accomplishments log.

When you finish a task:
1. Update `Context.md`: Status, the Roadmap checkboxes, an Accomplishments entry (date and what changed), and any decision with its reason.
2. Run `npm run lint`, `npm test`, and `npm run build`. All three must pass before work counts as done.
